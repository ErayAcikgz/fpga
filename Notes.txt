// Simulation Commands
iverilog -g2012 -o {outputFile} {verilogFile} {testBenchFile} -> Compiles simulation; -g2012: System Verilog support; -o: Specifies output; outputs .out
vvp {outputFile} -> Runs simulation; outputs .vcd
gtkwave {.vcdFile} -> Simulation waveform in GUI



// Gowin Project File Types

GowinSynthesis Constraints File -> .cst;
Physical/pin constraint file.
Maps RTL top-level ports to FPGA package pins.
Also defines IO standards, voltage bank settings, pull modes, and drive strength.

Memory Initialization File -> .mi, .hex, .mem;
Preloads block RAM or ROM with known values.
Used for lookup tables, coefficients, tiny CPU program memory, NN weights, and test patterns.

User Flash Initialization File -> tool-dependent;
Initializes external or internal flash contents.
Used to preload nonvolatile memory, boot data, constants, or stored configuration data.

GAO Config File -> GAO = Gowin Analyzer Oscilloscope;
Configures Gowin's internal logic analyzer/debug tool.
Similar idea to Xilinx ILA or Intel SignalTap.

GVIO Config File -> GVIO = Gowin Virtual Input/Output;
Controls or observes internal FPGA signals through Gowin debug infrastructure.
Useful for live FPGA debugging without routing every signal to physical pins.

GPA Config File -> GPA = Gowin Power Analyzer;
Configures power estimation and power analysis.
Used to estimate FPGA power consumption after synthesis/place-and-route.


// HDL Source File Extensions

.v -> Verilog source;
Old-style Verilog RTL.
Usually uses wire, reg, always @(*), and always @(posedge clk).

.sv -> SystemVerilog source;
Default format for RTL and testbenches.
Supports logic, always_ff, always_comb, typedef enum, parameter int, and stronger signed/type features.

.vh -> Verilog header;
Include file for Verilog macros and shared parameters.
Usually included with `include.

.svh -> SystemVerilog header;
Include file for SystemVerilog typedefs, packages, macros, and shared declarations.

.vhd / .vhdl -> VHDL source;
Another hardware description language.
Common in FPGA industry, especially older or European FPGA projects.


// Generated / Vendor File Extensions

.vo -> Verilog output netlist;
Generated by synthesis tools.
Do not hand-edit.

.vg -> Gate-level Verilog netlist;
Generated after synthesis or place-and-route.
Used for gate-level simulation or inspection.
Do not hand-edit.

.vp -> Protected/encrypted Verilog;
Vendor IP source that tools can compile but humans cannot meaningfully read.
Common for encrypted IP cores.

.edf / .edn -> EDIF netlist;
Tool-generated netlist format.
Used to pass synthesized logic between tools.

.blif -> Berkeley Logic Interchange Format;
Netlist format used by some open-source FPGA/logic synthesis flows.


// Constraint / Timing File Extensions

.cst -> Gowin constraints;
Pin locations, IO standards, voltage bank settings, pull modes, and drive strength.
Used for Tang Nano board builds.

.sdc -> Synopsys Design Constraints;
Timing constraint file.
Defines clocks, clock periods, false paths, multicycle paths, and timing requirements.

.xdc -> Xilinx constraints;
Xilinx constraint file.
Roughly combines pin constraints and timing constraints.

.qsf -> Intel/Altera Quartus Settings File;
Intel/Altera project settings and constraints.
Used for device, pin, IO, and build configuration.

.pcf -> Physical Constraints File;
Pin/physical constraint file used by some open-source FPGA flows.


// Simulation File Extensions

.vcd -> Value Change Dump;
Waveform output file.
Opened with GTKWave to inspect simulation signals.

.fst -> Fast Signal Trace;
More compact waveform format than VCD.
Also supported by GTKWave.

.out -> Simulation executable;
Common output from Icarus Verilog.
Generated by iverilog and executed with vvp.

.log -> Tool log;
Compiler, simulator, synthesis, implementation, or programming messages.
Useful for debugging tool errors.


// Memory / Initialization File Extensions

.mem -> Memory contents;
Generic memory initialization file.
Used for RAM/ROM contents.

.hex -> Hexadecimal data file;
Used for memory, program, coefficient, or test-vector initialization.

.mif -> Memory Initialization File;
Common FPGA memory initialization format.
Often used by vendor tools.

.coe -> Coefficient file;
Xilinx-style coefficient/memory initialization file.
Often used for filters, ROMs, and generated IP.

.mi -> Memory initialization file;
Tool-dependent memory initialization format.
Can be used by Gowin flows.


// FPGA Build Output File Extensions

.fs -> Gowin bitstream/programming file;
Generated FPGA configuration file.
Used to program the Tang Nano with openFPGALoader or Gowin tools.

.bit -> Xilinx bitstream;
Generated FPGA configuration file for Xilinx devices.

.sof -> Intel SRAM Object File;
Intel FPGA volatile programming file.
Configuration is lost after power-off unless stored in flash.

.pof -> Intel Programmer Object File;
Intel FPGA flash/nonvolatile programming file.

.bin -> Raw binary file;
Generic binary image.
Can be used for firmware, memory images, or converted bitstreams.

.jed -> JEDEC programming file;
Used for CPLDs and some older programmable logic devices.
